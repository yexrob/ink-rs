# Task: a checked-in generator for `src/text/width_data.rs`, and drop `unicode-width`

## Background

`src/text/width_data.rs` holds the Unicode tables behind ink-rs's string-width 8.3 port (`src/text/width.rs`). Its header says the tables came from temporary scripts that were never checked in, and the last table, `EAW_WIDE_OVERRIDES`, patches the `unicode-width` crate's widths toward get-east-asian-width. A release needs a generator anyone can rerun.

Ink's width rules: `node_modules/string-width/index.js` and `node_modules/get-east-asian-width/` in the Ink clone. get-east-asian-width's `eastAsianWidth` is 2 for East_Asian_Width W or F, else 1 (ambiguous as narrow).
