## 1. The API

- `Scope::use_node_ref() -> NodeRef`.
  - `NodeRef` is `Copy`, like `State`, so it moves into effect closures and `use_input` callbacks without a clone.
  - It is `PartialEq`, so it can be a component prop. Two refs are equal when they are the same hook slot.
- `View::node_ref(self, NodeRef) -> View` binds the ref to that View's host node.
- `measure_element(NodeRef) -> ElementMetrics`, a free function exported at the crate root.
  - `ElementMetrics` has `x`, `y`, `width`, `height`, `client_width` and `client_height`, with Ink's meanings (`src/measure-element.ts`):
    - `x` and `y` accumulate the offsets of the node and its ancestors, so they are relative to the root of the live tree.
    - `client_*` is the size without borders. Padding is not subtracted.
  - Use integer cells, as the rest of the public API does. The values are the rounded layout that paint uses.
  - It derives `Clone, Copy, Debug, Default, PartialEq, Eq`.

### Semantics

- `measure_element` returns the layout computed by the latest commit. Effects and event callbacks see the layout of the frame they follow.
  - A layout effect runs after layout, so it sees the new sizes.
  - During render it returns the previous commit's values, or zeros before the first layout. Ink returns zeros during render; returning the last layout is the design.md rule ("读到的是最近一次布局").
- It returns all zeros in these cases:
  - the ref is not bound to a View;
  - its View has unmounted;
  - its View has moved to another ref;
  - the component that owns the ref has unmounted. Do not panic here, unlike `State::get`.
- Binding follows React's ref attach and detach:
  - A ref is attached in the commit that mounts its View.
  - It is detached when the View unmounts or the View's `node_ref` changes.
  - Layout effects of that commit see the attached ref.
- Updating the stored metrics never marks a component dirty and never schedules a render.

### Implementation constraints

- After each `layout::compute` in a commit, and before that round's layout effects, refresh the metrics of the bound refs.
  - The cost must be proportional to the number of bound refs, not to the size of the tree.
  - A snapshot written into the ref's slot after layout is acceptable, and so is reading the host tree on demand. Choose one and explain it in the report.
  - The host tree is owned by `Runtime`, and effects run while no runtime borrow is held.
- Static is absolutely positioned (`Static::new` sets `Position::Absolute`, as Ink does), so it does not shift the coordinates of the live tree (ME9).
